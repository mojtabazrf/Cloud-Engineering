## Introducing Today's Project!

### What is Amazon Aurora?

Amazon Aurora is a fully managed relational database service compatible with MySQL and PostgreSQL, and it is useful because it provides high availability, scalability, and performance without requiring me to manage the underlying database infrastructure.

### How I used Amazon Aurora in this project

In today's project, I used Amazon Aurora to create a managed relational database and connect it to an EC2 instance.

### One thing I didn't expect in this project was...

One thing I didn't expect in this project was how important network configuration and security group rules are for allowing an EC2 instance to connect securely to an Amazon Aurora database.

### This project took me...

This project took me about 30 minutes, including documentation.

### Features of my EC2 instance

I created a new key pair for my EC2 instance because I need a secure way to authenticate and connect to the instance without using a password.

When I created my EC2 instance, I took particular note of the Public IPv4 DNS and the value for Key pair name because I would need the DNS name to connect to the instance remotely and the key pair to authenticate securely.
