## 📖 About This Repository

This repository is my public learning log for becoming a **Cloud Engineer**. I am following a structured roadmap of practical AWS projects. Every day I complete one project and document the full process: what I built, the steps I followed, the problems I faced, and what I learned.

**Why I do this:**

- Learn by building real things, not only by reading.
- Create a clear portfolio that shows my skills.
- Build the habit of writing good technical documentation.
- Stay consistent with a "one project per day" rhythm.

I come from a **system administration and IT infrastructure** background (networking, virtualization, Linux/Windows servers, monitoring). This roadmap helps me move that experience into the cloud.

## 📝 Documentation Template

Every project follows the same structure:

1. **Overview**: what the project is and what problem it solves
2. **Architecture**: a diagram or short description of the AWS services used
3. **Prerequisites**: tools, permissions, and accounts needed
4. **Step-by-step**: each action I took, with screenshots
5. **Verification**: how I tested that everything works
6. **Challenges & Fixes**: errors I met and how I solved them
7. **Key Learnings**: the main concepts I understood
8. **Cleanup**: how I deleted resources to avoid charges
